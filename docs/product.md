# 功能與使用限制

Otter 以支出群組整理旅行或聚會費用。每個群組有參與者、支出、餘額與結清建議。工作區分為「總覽、支出、成員、更多」四區；總覽優先顯示待結清項目與餘額，花費分析按需展開，「記一筆」則保持為主要動作。

## 帳號與登入

- 使用 Username 與密碼註冊、登入及登出。
- Username 會移除前後空白並轉成小寫；限 3–32 個英文字母、數字、底線或連字號，且不分大小寫、不可重複。
- 密碼至少 8 個字元。新帳號預設以正規化後的 Username 作為顯示名稱。
- 登入後可新增或移除多組 discoverable Passkey，登入時不必先輸入 Username。Passkey 需要 HTTPS secure context，或瀏覽器允許的 `localhost` 開發環境；密碼仍可作為備援。
- 帳號設定可建立具名稱、有效期 90 天的 API token，也可查看或撤銷手動及 device authorization token。明文 token 只顯示一次，伺服器只保存 SHA-256 hash。

為相容既有 client，註冊 API 仍接受選填的 `name`。開發環境預填 Username 為 `admin`。

## 支出群組

擁有者可以：

- 建立、選擇、重新命名及刪除群組。
- 設定基準貨幣與自訂匯率。
- 封存或還原群組。
- 透過 Username 邀請既有帳號成為協作者。
- 建立及撤銷唯讀分享連結。

同一帳號不能建立同名群組。協作者可以維護參與者與日常支出，但不能刪除群組、管理協作者或變更擁有者專屬設定。知道唯讀分享網址的人不需登入即可查看整個群組的支出、餘額與結清建議；連結外洩時，擁有者應立即撤銷。

## 參與者與支出

- 新增、重新命名、合併及刪除未被使用的參與者；同一群組內不能有同名參與者。
- 記錄支出的日期、描述、付款人、金額、貨幣與分帳參與者，並可修改或刪除支出。
- 支援平均、指定金額、比例及份數分帳，也可加入分類與標籤。
- 每筆支出可上傳一張 JPEG、PNG 或 WebP 收據，大小上限 5 MB。圖片目前儲存在 PostgreSQL。
- 顯示每位參與者的餘額，並產生 settle up 建議及結清紀錄。

新增支出預設使用今天、群組基準貨幣、第一位付款人、所有參與者與平均分帳。進階欄位按需展開；提交前會顯示每人的實際分帳金額。

## 貨幣

支援 TWD、JPY、USD 與 EUR。所有餘額都換算為群組的基準貨幣。未設定自訂匯率時，系統會自動使用台灣銀行即期買進與賣出的中價，報價快取 15 分鐘；台灣銀行暫時無法使用時則改用內建固定匯率。

可在「更多 → 換算方式」預覽並保存群組專用的自訂匯率。自訂值優先於銀行報價；清除自訂值即可恢復自動更新。自動取得的報價不會保存至群組或 JSON 備份。

## 匯入、匯出與備份

- 匯出支出、餘額及結清建議 CSV。
- 批次匯入同格式的支出 CSV。匯入前須先建立對應參與者；任一列有誤會取消整批匯入。
- 下載 JSON 備份，再還原為新的支出群組，不覆蓋既有資料。
- JSON 備份不含帳號、session、密碼或收據圖片。
- 透過列印動作輸出適合列印的結算畫面。

CSV 範例：

```csv
date,description,amount,currency,paid_by,category,tags,split_participants
2026-06-25,Dinner,1200,TWD,Alice,餐飲,"food|night","Alice; Bob"
```

## 操作安全

修改基準貨幣或匯率，以及執行 CSV 匯入、JSON 還原、分享、封存、合併或刪除前，介面會先顯示結果或影響範圍。取消、按 Escape 或捨棄草稿不會送出 mutation；失敗時保留原資料與草稿。

封存及唯讀分享畫面不提供修改控制項。離線時只能閱讀已載入資料，所有寫入動作都需要連線。安裝成手機主畫面捷徑不會加入離線新增或同步功能。
