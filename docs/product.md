# 功能與使用限制

Otter 以支出群組整理旅行或聚會費用。每個群組有參與者、支出、餘額與結清建議。工作區分為「總覽、支出、成員、更多」四區；總覽優先顯示待結清項目與餘額，花費分析按需展開，「記一筆」則保持為主要動作。

## 介面語言

網頁介面提供 18 種語言：

- 正體中文（`zh-TW`）、English（`en`）、日本語（`ja`）、한국어（`ko`）。
- Hindi（`hi`）、Spanish（`es`）、French（`fr`）、Portuguese（`pt`）、Indonesian（`id`）、German（`de`）、Vietnamese（`vi`）。
- Turkish（`tr`）、Filipino（`fil`）、Thai（`th`）、Italian（`it`）、Polish（`pl`）、Malay（`ms`）、Dutch（`nl`）。

可在登入畫面、帳號選單或帳號設定切換語言；選擇只儲存在目前瀏覽器，不會同步至帳號。未儲存有效選擇時，依瀏覽器語言偏好順序使用第一個支援的語言；沒有符合項目時使用 English。地區標籤使用同一份語言翻譯，例如 `es-MX` → `es`、`pt-BR`／`pt-PT` → `pt`、`fr-CA` → `fr`；瀏覽器的 `tl`／`tl-PH` 使用 Filipino（`fil`）。儲存的選擇只接受上述正式代碼。

語言切換只影響介面、錯誤提示與金額／日期顯示，不會改變群組資料、輸入格式、支援的貨幣或 CLI 語言。新增的 14 份翻譯仍需完成流暢使用者審閱；狀態與用語選擇見 [Browser localization](localization.md)。

## 帳號與登入

- 使用 Username 與密碼註冊、登入及登出。
- Username 會移除前後空白並轉成小寫；限 3–32 個英文字母、數字、底線或連字號，且不分大小寫、不可重複。
- 密碼至少 8 個字元。新帳號預設以正規化後的 Username 作為顯示名稱。
- 登入後可新增或移除多組 discoverable Passkey，登入時不必先輸入 Username。Passkey 需要 HTTPS secure context，或瀏覽器允許的 `localhost` 開發環境；密碼仍可作為備援。
- 帳號設定可建立具名稱、有效期 90 天的 API token，也可查看或撤銷手動及 device authorization token。明文 token 只顯示一次，伺服器只保存 SHA-256 hash。

為相容既有 client，註冊 API 仍接受選填的 `name`。開發環境預填 Username 為 `admin`。

## 支出群組

擁有者可以：

- 建立、選擇、重新命名及刪除群組。
- 在「更多 → 複製群組」建立未封存的新群組（封存來源也可複製）：名稱加上 ` (copy)` 或流水號，複製成員、基準貨幣與自訂匯率，並重新產生成員 ID；不複製支出、結清紀錄、協作者、分享連結或 API 寫入權限，原群組不變。擁有者可使用 `POST /api/trips/:tripId/copy` 取得新群組資料（HTTP 201）。
- 設定基準貨幣與自訂匯率。
- 封存或還原群組。
- 透過 Username 邀請既有帳號成為協作者。
- 建立及撤銷三種分享連結：唯讀、登入後加入協作者、免登入持連結即可編輯。

同一帳號不能建立同名群組。協作者可以維護參與者與日常支出，但不能刪除群組、管理協作者或變更擁有者專屬設定。唯讀連結不需登入即可查看支出、餘額與結清建議，不公開收據、協作者及付款紀錄。登入後編輯連結要求使用者登入或註冊，開啟連結後成為協作者；撤銷連結只阻止新加入，已加入者須由擁有者在協作者清單另行移除。免登入編輯連結讓持有者修改群組資料（包括收據與結清紀錄），但無法管理權限或群組設定；每次請求都驗證連結，撤銷後立即停止新操作。連結外洩時應立即撤銷；已取走的資料無法收回。

## 參與者與支出

- 新增、重新命名、合併及刪除未被使用的參與者；同一群組內不能有同名參與者。
- 記錄支出的日期、描述、付款人、金額、貨幣與分帳參與者，並可修改或刪除支出。
- 桌面與手機的每筆支出列最右側提供 `⋯` 選單，包含「編輯支出、複製為新支出、修改紀錄、刪除支出」。點選名稱仍可開啟編輯；刪除必須再次確認，失敗時保留確認視窗與錯誤提示。封存群組僅提供修改紀錄，唯讀分享不提供此選單；離線時無法刪除。
- 支援平均、指定金額、比例及份數分帳，也可加入分類與標籤。
- 新增支出時可選擇照片，或在支援的手機瀏覽器使用「拍照」（以瀏覽器提供的相機選擇為準）；建立支出後上傳收據。每筆支出可上傳一張 JPEG、PNG 或 WebP 收據，大小上限 5 MB，不支援 HEIC；圖片目前儲存在 PostgreSQL。若支出建立成功但上傳失敗，可在畫面重試上傳，或稍後到該筆支出的編輯畫面補傳，重試不會新增第二筆支出。
- 在「成員」可指定某位成員的結算算在另一位成員身上（例如孩子算在家長身上），或改回自行結算。支出分攤及付款紀錄仍保留原成員；計算餘額與結清建議時將其淨額併入代表人，被歸屬成員的顯示餘額為零。不能指定自己、跨群組成員，或形成多層歸屬；刪除代表人會解除歸屬，合併代表人會讓被歸屬成員改算在保留的成員身上。JSON 備份包含歸屬，還原後依新成員 ID 重建。
- 顯示每位參與者的餘額，並產生 settle up 建議及結清紀錄。

未設定個人偏好時，新增支出預設使用今天、群組基準貨幣、第一位付款人、所有參與者與平均分帳。進階欄位按需展開；提交前會顯示每人的實際分帳金額。

### 成員帳務與快速記帳

總覽依序呈現群組概況、待結清／每人餘額、最近支出與花費分析。不需選擇個人身分；「每人餘額」提供速覽，「花費分析 → 成員帳務」提供全員比較，桌面以表格呈現，手機以精簡列卡呈現。「記錄付款」僅放在待結清區。

支出預設僅保存於目前瀏覽器，依帳號與群組隔離，不跨裝置同步、不含於備份。登入使用者可在「群組設定 → 此瀏覽器的支出預設」清除本群組的貨幣與分帳預設；協作者、封存群組及離線狀態仍可使用，不刪除支出、登入資料或離線佇列。未登入訪客不提供此控制。儲存失敗時提示未保存，本次有效預設仍可使用。

舊版「我是誰」設定不再套用至新增支出的付款人。開啟群組時只清理目前帳號在該群組的舊身分欄位，保留有效貨幣與分帳預設，不掃描其他帳號或群組。清理失敗時仍忽略舊身分，並提示儲存失敗。回復舊版時需重新選擇身分，不會依登入帳號猜測。

新增支出表單可明確按「記住貨幣與分帳設定」，保存目前貨幣、分帳成員、模式及其輸入值，不保存描述、總金額或收據。取消表單不自動保存設定，但不撤銷先前明確按下的保存操作。偏好只用於新表單初始化，不覆蓋既有支出、待同步草稿或已輸入的內容。指定金額與新總額不符時須先修正分帳預覽；系統不自動縮放。成員遭刪除或合併使分帳設定失效時，清除失效設定並提示重新選擇，不依名稱推測成員。

桌面與手機支出列表均在每列最右側的 `⋯` 選單提供「複製為新支出」。複製先開啟可編輯表單，日期改為今天，保留描述、原幣金額、貨幣、付款人、分帳對象、分類與標籤；不複製收據、修改紀錄、付款紀錄或匯率快照。已保存指定分攤金額的來源以指定金額初始化，其他來源以平均分帳初始化；無法還原原始比例或份數輸入。來源內容優先於個人預設。儲存後建立新支出，伺服器依新日期與現有規則取得匯率；離線排隊時仍以同步時的規則為準。取消不建立支出，來源支出不變。封存及唯讀畫面不提供複製操作。

成員帳務以目前結清幣別顯示「實付、分攤、待收／待付」。實付為替群組支付店家等支出的金額，不含成員間結清轉帳；分攤為該成員應負擔的支出。待收／待付包含已記錄付款與代表人調整，與上方每人餘額一致。以上均不包含待同步草稿；既有支出分析圖表仍使用群組基準幣別。

每位成員的「查看明細」可展開支出、分攤、付款／收款及代表人調整；金額沿用既有換匯與分攤尾差規則。唯讀分享未公開付款紀錄時，只顯示可公開的支出明細，並說明付款與調整明細不可用，餘額仍以群組結果為準。零餘額顯示「已結清」；有代表人時另提示由誰結算，不表示本人已有付款紀錄。代表人的餘額可能包含其他成員，不等於其實付減分攤。

## 支出修改紀錄

支出頁的「修改紀錄」列出群組的新增、修改與刪除；每筆支出列的 `⋯ → 修改紀錄` 或編輯畫面的「修改紀錄」可查看該筆歷史。紀錄包含當時的操作者、時間、版本與欄位差異，僅目前的 owner、editor 可讀，封存群組仍可查看；唯讀分享連結不公開歷史，免登入編輯連結視為 editor。

- 編輯、刪除與收據操作都檢查開始操作時的版本。其他人已修改時，不覆蓋資料、不自動重送；表單保留草稿，先查看最新內容，再明確確認保留草稿繼續編輯。確認不是自動合併，儲存前須檢查所有欄位。若成員合併使草稿的付款人或分帳選擇失效，介面會先說明；明確確認後只將失效設定改用最新支出的設定，其餘草稿保留。指定金額與保留的總額不一致時，須先修正分帳預覽才能儲存。
- CSV 匯入、備份還原、成員合併與收據變更也會留下紀錄。一般成員改名不建立支出版本，舊快照仍顯示當時的名稱。
- 既有支出從啟用功能時的「起始快照」開始，無法追溯更早的修改或原操作者。
- 刪除支出只移除目前帳目，歷史仍保留；刪除整個群組才清除其歷史。目前不提供還原舊版或復原刪除。
- 收據歷史只保留識別資訊與格式，舊圖片無法查看。紀錄不是防竄改稽核，也不能重建歷史餘額或替代付款紀錄。

## 貨幣

支援 TWD、JPY、USD、EUR、SGD、GBP、AUD、CAD 與 KRW。所有餘額都換算為群組的基準貨幣。新支出未設定自訂匯率時，系統會使用台灣銀行即期買進與賣出的中價（報價快取 15 分鐘）；台灣銀行暫時無法使用時改用內建固定匯率。同一基準貨幣下，後續報價或群組自訂匯率變動不改變已記錄支出的換算金額、分帳與其結清建議。付款紀錄目前仍使用即時有效匯率，因此有外幣付款時，整趟餘額可能變動。改基準幣時，舊快照仍保留原基準幣；透過當下匯率再換算到新的基準幣，金額可能變動。

### 離線新增支出（僅已載入的登入頁面）

已登入的群組 owner／editor、已載入且未封存的群組，在頁面仍開啟但網路中斷時可填寫並存入此裝置的待同步清單。儲存成功後才顯示「尚未同步」；儲存空間滿或私密模式不允許 IndexedDB 時顯示錯誤，保留表單，不宣稱已保存。離線刷新或關閉後冷啟動不保證可使用介面；應先重新連線載入。登出或切換帳號只暫停舊帳號草稿，不自動刪除或跨帳號重送；公用裝置使用者應在登出前自行核對並明確刪除本機草稿。

待同步清單只保存在目前瀏覽器／裝置，不是備份；清除網站資料或瀏覽器回收 IndexedDB 會使草稿遺失。清單可檢視數量、狀態、編輯尚未送出或已確定未記帳的草稿、確認後刪除本機草稿；已送出但回應不明者不能修改，只能用相同操作 ID 與原資料重試，或確認後刪除本機資料（伺服器可能已記帳，須先核對群組）。恢復連線、回到頁面及頁面保持開啟期間會嘗試同步；編輯待同步草稿時會先暫緩同步，直到存檔或取消編輯；失去登入狀態後，本頁不再自動重試，重新登入並載入工作區後才恢復；權限、封存或資料衝突停止自動重試並保留原草稿，恢復權限後可手動以原請求重試。參與者變更而伺服器確定未記帳時，先更新群組資料再開放修正草稿，並以新操作 ID 再送。編輯未保存的草稿時，切換群組須先確認捨棄變更；其他分頁刪除當前草稿時，本頁會關閉該編輯器。若群組已被刪除或帳號無法再存取，登入後可在群組側欄（沒有可存取群組時在空畫面）查看本機殘留草稿，核對可能已記帳的請求後明確刪除；不會替無法存取的群組自動重送。

離線預覽僅為原幣分帳，不是即時匯率；**同步時**由伺服器依當時有效銀行、自訂或固定匯率建立支出快照。待同步金額不計入正式餘額或結清建議；成功後重新載入群組結果。離線草稿不儲存照片；若已選照片後才離線，須先重新連線或移除照片才可存草稿。其他寫入（既有支出修改／刪除、付款、參與者、收據、設定）仍須連線。公開分享／訪客 token 不支援本機排隊，也不跨裝置同步草稿。

### 群組自訂匯率

可在「更多 → 換算方式」預覽並保存群組專用的自訂匯率。自訂值優先於銀行報價；清除自訂值只影響未來的新支出。已記錄的支出保存當時使用的每 1 原幣對基準幣匯率與來源；銀行來源還保存 Bank of Taiwan、spotMid 與報價時間。群組不保存自動報價，但支出快照會進入版本紀錄及 JSON 備份。若銀行無法取得，新增支出保存內建固定匯率（無報價時間）；舊支出／舊備份匯入以 `legacy` 標示為估算，不能當作歷史銀行報價。

## 匯入、匯出與備份

- 匯出支出、餘額及結清建議 CSV。
- 批次匯入同格式的支出 CSV。匯入前須先建立對應參與者；任一列有誤會取消整批匯入。
- 下載 JSON 備份，再還原為新的支出群組，不覆蓋既有資料。
- JSON 備份不含帳號、session、密碼、收據圖片或修改紀錄；還原支出以新 ID、version 1 開始，來源標為備份還原。包含完整歷史與目前收據的災難復原須使用 PostgreSQL 備份。
- 透過列印動作輸出適合列印的結算畫面。支出列表列印時隱藏每列的操作選單與操作欄，保留支出名稱及金額；返回螢幕顯示後可繼續使用選單。

CSV 範例：

```csv
date,description,amount,currency,paid_by,category,tags,split_participants
2026-06-25,Dinner,1200,TWD,Alice,餐飲,"food|night","Alice; Bob"
```

## 操作安全

修改基準貨幣或匯率，以及執行 CSV 匯入、JSON 還原、分享、封存、合併或刪除前，介面會先顯示結果或影響範圍。取消、按 Escape 或捨棄草稿不會送出 mutation；失敗時保留原資料與草稿。

封存及唯讀分享畫面不提供修改控制項。離線時除上述本機新增支出草稿外，只能閱讀已載入資料；其他寫入動作都需要連線。安裝成手機主畫面捷徑不會加入離線冷啟動功能。
